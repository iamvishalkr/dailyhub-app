**DailyHub** is a clean and minimal daily productivity companion built with React Native + Expo.  
It started as a habit tracker, but brings together multiple simple tools to help organize your everyday life.

Track habits, manage quick tasks, write journals, and keep up with your medication schedule — all in one lightweight app.

---

## Features

### 🔥 Habit Streak Tracker

Build better routines by tracking your daily habits.

- Create and manage habits
- Track completion streaks
- Stay motivated with daily progress

---

### ✅ Quick Todo

A simple and fast todo system for everyday tasks.

- Tap to quickly add tasks
- Mark tasks as completed
- Easily edit and manage your list

---

### 📝 Simple Journal

Capture your thoughts and daily reflections.

- Markdown supported entries
- Questionnaire-based journaling
- Simple writing experience

---

### 💊 Pills & Medicine Tracker

Never miss your medication schedule.

- Add medicines
- Track daily intake
- Manage health routines easily

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/dailyhub.git
cd dailyhub
```

Install dependencies:

```bash
pnpm install
```

Start development server:

```bash
npx expo start
```
